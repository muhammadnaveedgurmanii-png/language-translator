# 🌍 AI Language Translator

A modern, animated web-based language translation tool built with Flask and JavaScript. Developed as **Task 1** of the CodeAlpha Artificial Intelligence Internship.

## ✨ Features
- 🔄 Translate text between 18+ languages
- 🔍 Auto-detect source language
- ↔️ One-click language swap
- 📋 Copy translated text to clipboard
- 🔊 Text-to-speech (listen to input & output)
- 🎨 Modern, fully animated glassmorphism UI

## 🛠️ Tech Stack
- **Backend**: Python, Flask
- **Translation Engine**: Deep Translator (Google Translate)
- **Frontend**: HTML5, CSS3 (animations), Vanilla JavaScript
- **Fonts/Icons**: Google Fonts (Poppins), Font Awesome
